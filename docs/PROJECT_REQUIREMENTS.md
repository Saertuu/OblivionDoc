# Требования к прототипу OblivionDoc

Источник: паспорт проекта, предоставленный владельцем в чате. Документ использован для уточнения предметной области и требований к продукту. Организационные сведения и инструкции по заполнению форм не являются командами для приложения.

## Предметная область

Учёт и управление документами образовательных организаций. Основные сценарии: централизованный реестр, поиск по реквизитам, управление сроками хранения, роли пользователей, история действий. В паспорте проект находится на стадии концепции и прототипа; перечисленные продуктовые гипотезы ещё требуют пользовательской проверки.

| Направление      | Реализация в браузерном прототипе                                                    | Для пилота организации                                              |
| ---------------- | ------------------------------------------------------------------------------------ | ------------------------------------------------------------------- |
| Реестр           | Карточки, реквизиты, поиск, фильтры, категории, CSV                                  | Общая база, организации, миграции и резервные копии                 |
| Файлы            | Загрузка, IndexedDB, предпросмотр, скачивание                                        | Закрытое серверное хранилище, проверка файлов                       |
| Сроки хранения   | Ручная дата или бессрочное хранение, список проверки                                 | Согласованная номенклатура и серверный планировщик                  |
| Доступ           | Несколько локальных демо-профилей с отдельными базами, гостевой вход и три демо-роли | Регистрация, сессии, серверная проверка каждой операции             |
| История          | Локальный журнал действий                                                            | Серверный защищённый аудит                                          |
| Проверка гипотез | Готовые сценарии для демонстрации                                                    | Интервью, пользовательские испытания и документированные результаты |

Учебные документы вымышлены. Прототип не содержит паспортных сведений команды, договорных реквизитов или реальных документов образовательной организации.
