# OblivionDoc

Начальная визуальная концепция нового сайта. Это пока не перенос функций оригинального проекта: исходный репозиторий пуст, а доступ к https://obliviondoc-site.onrender.com/ из среды блокируется сетевым прокси (HTTP CONNECT 403). Необходимо изучить оригинал или получить описание его назначения, разделов и пользовательских сценариев. Не следует считать текущую страницу готовым сайтом или публиковать её как завершённый продукт.

## Разработка

Node.js >= 22.12.0.

```sh
cd /workspace/OblivionDoc
npm ci --cache /workspace/.npm-cache
npm run dev
```

В конфигурации Vite сервер разработки доступен на всех интерфейсах. Для сборки и локальной проверки:

```sh
npm run build
npm run preview
```

## Проверки

```sh
npm run test:e2e
```

Браузерные проверки используют Chromium Playwright. Если браузер отсутствует, установите его через `npx playwright install chromium` (на Linux также нужны системные зависимости браузера). В облачной среде с готовым Chromium можно передать путь через `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`.

## Основа интерфейса

- React и TypeScript; Vite для разработки и production-сборки.
- Manrope хранится локально в пакете; внешние CDN не требуются.
- Тёмная и светлая темы, сохранение выбора, мобильная навигация.
- Анимации учитывают `prefers-reduced-motion`, интерфейс поддерживает клавиатуру.
- Цвета находятся в `src/tokens.css`; оформление — в `src/styles.css`.
- Метатег `noindex` установлен до появления окончательного содержания.

Серверной части, авторизации, базы данных и интеграций пока нет: их требования зависят от назначения оригинального проекта.

## Публикация текущей концепции

Workflow `.github/workflows/pages.yml` собирает сайт и публикует его в GitHub Pages после отправки в ветку `main`. В настройках репозитория Settings → Pages → Build and deployment нужно выбрать Source: GitHub Actions. Не меняйте видимость приватного репозитория ради публикации без отдельного разрешения владельца.

Относительная база Vite позволяет обслуживать сборку как из корня домена, так и из подкаталога. Реальный публичный адрес следует брать из успешного запуска задания Deploy; до завершения задания публикация не подтверждена. Индексирование концепции отключено метатегом `noindex`.
